## 1. 机构类型图谱（2026-08-18）

| 类型 | 出资 / 登记 | 运营主体 | 收费 | 定位与痛点 |
|---|---|---|---|---|
| 公办公营 | 政府出资 | 政府 / 事业单位 | 低，兜底价 | 特困 / 低保等民政对象优先，常"一床难求" |
| 公办民营（公建民营） | 政府建物业、社会力量运营 | 民办非企业团队 | 优惠价 | 所有权与运营权分离，非营利为主，考核+退出机制 |
| 民办非营利 | 民间投资 | 民办非企业（民政登记） | 政府指导价 | 利润再投入不分红，享建设/运营补贴、免税、水电气居民价 |
| 民办营利 | 民间投资 | 公司（工商登记） | 市场价 | 可分配利润，投资回收期长、经营风险高，服务品质弹性大 |
| 社区嵌入式 | 政府 / 社区 | 就近运营 | 普惠 | 日间托养 + 居家上门，链接家庭与社会，村/社区级 |

补充（新框架）：2026-04 贵州出台《养老机构分类分级管理办法（试行）》，按功能重分为 **兜底保障型 / 普惠支持型 / 完全市场型** 三类，并细分市/县/乡镇/村（社区）四级。这是"十五五"更贴近政策口径的新分类，看招聘/政策时比"公办民办"二分更准。

## 2. 运营模型与保本线（2026-08-18）

- **重资产模型**：床位固定成本刚性（房租 / 人工 / 能耗 / 折旧），入住低时现金流先断——印证能力画像第 1 维"预算与成本"。
- **关键数字**：2024 全国养老机构平均入住率仅 **45.4%**（民政部《2024年度国家老龄事业发展公报》），远低于盈亏平衡线；业内公认入住率 **≥60%** 才覆盖运营成本，部分观点需 70-80%。
- **规模效应**：60 张床位以下难收回成本，理想规模约 **100 张**（分摊固定成本）。
- **成本结构**（张乃子 / 上海交大）：房租 20-25% + 人力 35-45% + 运营 10% + 折旧 10%。民办非企业人工成本占营收已从 15 年前约 24% 升到约 52%。
- **单床经济**（平凉测算）：每张床位建设成本约 17 万；入住 100 人达盈亏临界；200 床满负荷年利润约 192 万、收回成本约 16 年。
- **结构性差异**：护理院 / 失能机构入住率高（刚需），活力 / 轻度失能机构入住率低。

**对"管理一个机构"的含义**：保本线第一变量是 **入住率**（→ 获客 / 区位 / 口碑），第二是 **人力成本近半**（→ 团队管理硬能力）；长护险后合规拿补贴可改善现金流。这把第 5 项"招满率运营获客是你真缺口"用行业数据坐实了。

## 3. 收入结构（2026-08-18）

- **主体（南京民办抽样）**：床位费 **36%** + 护理费 **32%** + 伙食费 **15%** = **83%**，三项为绝对主力。
- **护理驱动**：失能机构护理费占比可达 **55-71%**（南昌中等水平养老院），越是刚需护理占比越高、定价权越强。
- **政府补贴（增量）**：一次性建设补助（护理型床位 5000-10000 元/张）、运营补贴、护理补贴（约 120-150 元/月/人）、水电气热按居民价。
- **长护险支付**：49 个试点城市、1.88 亿人参保（2024 末），支付重度失能照护，正成机构新增收入源（详见双周精编）。

**对管理岗含义**：收入 80%+ 押在床位 / 护理，意味着"卖床位 + 留护理"是生死线（呼应能力画像第 2 维获客）；补贴 / 长护险是利润调节器，需专人盯政策合规（第 3 维）。

## 5. 管理岗能力画像（2026-08-17 sprint2 红队产出）

**收敛题**：管理一个机构，最该先补的能力是「预算」还是「招满率」？

**红队双方各 3 条**
- 先补预算（生存线）：① 养老机构重资产、床位固定成本每月刚性（房租/人工/能耗），入住低时现金流先断，先活下来才能谈招满；② 招满率受区位/口碑/竞品影响，部分不在院长控制内，但成本结构在院长控制内，先控本才有议价空间；③ 你会算账，才能判断"降价促入住"是否划算，否则被销售带节奏。
- 先补招满率（收入源，反方）：① 民办机构收入几乎全靠床位费/服务费，空置即零收入，预算再省也填不满空床的坑；② 招满率牵动口碑飞轮：入住高→样本多→服务打磨快→转介绍多，比纯控本增长快；③ 你建筑背景强协调流程，但缺"卖床位"的客户视角，只懂省不懂获客，机构成低成本空壳。

**结论（不附和）**：两者不是二选一，关键在阶段——开业 0-6 个月先招满率（没收入预算无意义），稳定期先预算（防扩张失控）。对你（无养老履历、欲走管理）更稀缺的能力其实是"招满率背后的运营获客"，因为预算会计逻辑你 8 年项目管理已部分具备；真正缺口在"怎么把床位卖出去且留住"，这是养老运营最被低估的能力。

**能力画像 4 维**
1. 预算与成本（你已有基础，补养老单床经济）
2. 招满率运营获客（你真缺口，重点补）
3. 合规（长护险后硬约束，见双周精编）
4. 团队与 AI 提效（监督智能，见 [[Prompt 库]] 卡片 3）

### 6.3 对照信号（辩证看，不单向乐观）
- 入住率两极：社区嵌入 / 公建民营标杆（橡树 93%、和睦 92%、长乐 95%）近满床；钱塘区 4 家机构整体仅 25%（2025 民政答复），低端公办混合也空置。差异不在"床位多少"，在区位 + 定位 + 获客系统。
- 高端连锁靠"资本 + 品牌 + 保险转化"撑获客，非新人可复制的运营手艺；社区嵌入式 / 普惠型靠"地缘 + 口碑 + 医保 + 转介绍"，是管理岗新人最能练"把床位卖出去且留住"的场。
- 定价分层清晰：高端 1.1 万-2.5 万、普惠 3500-8000、社区嵌入 3500-7500。你的目标岗（运营总监 / 院长）多落在普惠 / 社区嵌入与中端连锁之间，而非顶奢 CCRC。

### 6.4 喂养能力画像第 2 维（招满率运营获客）
- 真缺口落点：社区嵌入式 / 普惠连锁的"日常获客系统"（大众点评运营、转介绍率管理、医保定点带来的信任、社区活动转化），比高端连锁的"品牌砸钱"更值得学。
- 待核字段：护理岗公开薪酬区间本次检索未稳定析出（招聘平台数据时效性强），列为下轮核实项，不臆造。
