# 卧推

> [!info] 一句话要点
> 仰卧推胸，建立上肢推力的基础动作。

## 目标肌群
- 主要：胸大肌
- 次要：三角肌前束、肱三头肌

## 动作步骤
1. 躺在卧推凳上，杠铃位于眼睛正上方，双手略宽于肩。
2. 肩胛骨收紧下沉，腰部自然弓起，脚踩实地面。
3. 控制杠铃下放至胸部（乳头附近），小臂垂直。
4. 发力推起至手臂伸直，不要锁死肘关节。

## 技术要点
- 全程收紧肩胛，避免耸肩。
- 杠铃轨迹略呈弧线（落胸→推向上胸上方）。
- 手腕中立，杠铃压在掌根。

## 常见错误
- 肘部外展 ~90° 过大 → 肩峰受压，改为 45-60°。
- 臀部离凳 → 失去下肢支撑。
- 低头看杠 → 颈椎受力。

## 变式 / 进阶
- 上斜卧推（上胸）、哑铃卧推（活动度更大）、地板卧推（锁定点训练）。
