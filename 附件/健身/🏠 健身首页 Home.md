# 🏋️ 健身知识库

欢迎来到你的**健身第二大脑**！这里用来管理训练、动作、营养、计划与恢复，所有内容都是本地 Markdown，和主库（[[🏠 首页 Home]]）共享同一个 vault。

## 🚀 从这里开始
- 📇 [[📇 健身索引 Index]] —— 所有健身主题的入口
- 🏷️ [[🏷️ 健身标签地图 Tags]] —— 按标签浏览
- 📝 记一次训练：插入模板 → `90 模板/训练日志模板`
- 💡 记录动作：插入模板 → `90 模板/动作卡片模板`

## 🗂️ 五大板块
| 板块 | 入口 | 用途 |
| --- | --- | --- |
| 动作库 | [[📇 动作总览 MOC]] | 按部位整理动作卡（步骤/要点/错误） |
| 训练计划 | [[📇 计划总览 MOC]] | 周期化计划项目 |
| 领域 | `健身/领域/` | 力量/有氧/营养/恢复/补剂 长期知识 |
| 食谱 | [[📇 食谱总览 MOC]] | 饮食与宏量追踪 |
| 训练日志 | [[📇 训练日志索引]] | 每次训练的记录（数据沉淀） |

## 🔁 核心循环
1. **学动作** → 在 `动作库` 建动作卡
2. **排计划** → 在 `训练计划` 建周期化方案，链入动作
3. **做训练** → 每次用 `训练日志模板` 记数据
4. **看趋势** → 在 `训练日志索引` 回顾进步
5. **调营养** → 在 `食谱` 配合饮食
