# 🏋️ 健身知识库（主库下的「健身」子库）

这是你主知识库 `D:\Obsidian Vault` 里的一个**健身子库**，和通用笔记共享同一个 vault、同一套 Obsidian 配置（核心插件、模板目录、外观都已就绪）。你打开主库时，左侧文件树里就能看到 `健身/` 文件夹。

---

## 1. 怎么打开
直接用 Obsidian 打开主库 `D:\Obsidian Vault`（和之前一样）。`健身/` 会出现在文件树中，点开 `健身/🏠 健身首页 Home` 即可。

---

## 2. 文件夹结构
| 文件夹 | 用途 |
| --- | --- |
| `健身/动作库/` | 按部位（上肢/下肢/核心/有氧）整理动作卡 |
| `健身/训练计划/` | 周期化训练计划项目 |
| `健身/领域/` | 力量/有氧/营养/恢复/补剂 长期知识 |
| `健身/食谱/` | 饮食与宏量追踪 |
| `健身/训练日志/` | 每次训练的记录（数据沉淀） |
| `健身/资源/` | 书摘、文章、视频、工具 |
| `健身/附件/` | 动作演示图等 |

> 健身专属模板放在**共享的** `90 模板/` 里（`训练日志模板` / `动作卡片模板` / `食谱模板` / `健身计划模板`），核心模板插件直接能插入。

---

## 3. 日常用法

- **记一次训练**：`Ctrl/Cmd + P` → 模板：插入模板 → 选 `训练日志模板` → 填动作表。
- **加一个动作**：插入 `动作卡片模板`，存到 `健身/动作库/<部位>/`。
- **排计划**：插入 `健身计划模板`，存到 `健身/训练计划/`，用 `[[动作]]` 链入动作库。
- **看趋势**：打开 `健身/训练日志/📇 训练日志索引`，装 Dataview 后自动汇总。
- **营养配合**：在 `健身/食谱/` 用 `食谱模板` 记宏量。

### 推荐的核心循环
学动作 → 排计划 → 做训练（记日志）→ 看趋势 → 调营养。

---

## 4. 社区插件（和主库一致）
本子库依赖 **Dataview** 来生成自动列表（标签地图、训练日志索引、动作/食谱汇总）。安装方式见主库 `README.md`：
设置 → 第三方插件 → 关闭安全模式 → 浏览 → 搜 `dataview` → 安装并启用。

其余推荐插件（Templater / QuickAdd / Calendar 等）同样参考主库 README。

---

## 5. 与主库的关系
- 健身笔记的标签带 `#fitness`，会出现在主库 `📇 总索引` 的 MOC 列表里——实现「一个大脑」互联。
- 通用笔记也能 `[[链接]]` 到健身内容（反之亦然），知识网络自然打通。
