# 健身记录仓库 · README

一个专门用来**记录**你健身训练与个人身体数据的 Obsidian 仓库。
与另一个「健身计划」仓库互补：计划管"怎么练"，本仓库管"练了什么、练得怎样"。

## 一、如何打开
1. 打开 Obsidian
2. 菜单「打开文件夹作为仓库」
3. 选择 `D:\Obsidian Vault\健身记录`
4. 完成，开箱即用。

## 二、文件夹结构
| 文件夹 | 用途 |
|--------|------|
| 00 索引 | 首页 Home、训练记录总览 MOC |
| 10 个人资料 | 身体数据（身高/体重/体脂/BMI/骨骼肌 + 历史） |
| 20 训练记录 | 每次训练的记录文件（每日笔记按钮自动生成） |
| 90 模板 | 训练日模板（核心 Templates 语法） |

## 三、日常用法
- **记一次训练**：左侧「每日笔记」按钮（或命令面板 Daily notes），自动套用训练日模板，落在 `20 训练记录`，文件名即当天日期。
- **插模板**：笔记里输入 `/` 调出 Templates，选「训练日模板」。
- **看总览**：打开 [[📇 训练记录总览 MOC]]。
- **个人数据**：更新 [[身体数据]]。

## 四、已启用核心插件
Templates、Daily notes、Backlink、Graph、Tag pane 等。
模板语法用核心 `{{date}}` / `{{title}}`，**离线即可用，不依赖社区插件**。

## 五、推荐社区插件（联网后安装，非必需）
- ⭐ Dataview：让 MOC 自动聚合训练记录列表
- ⭐ Templater：比核心模板更强（装后可升级模板语法）
- ⭐ Calendar：日历视图快速跳到某天训练
- 🔧 Obsidian Git：版本备份（需先装 Git）

## 六、核心原则
- 每次训练如实记录组/次/重量，专业训练看"容量"和"趋势"，不只看单组重量。
- 个人数据定期更新（建议每 4 周体测一次），用 [[身体数据]] 看长期变化。
- 记录比计划更重要：真实数据才能指导下次怎么调。
