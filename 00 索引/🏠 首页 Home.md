# 🏠 我的第二大脑

欢迎！这是一个用 [Obsidian](https://obsidian.md) 搭建的**个人知识库**。所有笔记都是本地 Markdown 文件，数据完全归你所有。

## 🚀 从这里开始
- 📇 [[📇 总索引 Index]] —— 所有主题的入口地图
- 📥 [[📥 收件箱 Inbox]] —— 还没整理的原始想法
- 🗓️ 每日笔记：左侧「每日笔记」按钮，或 `Ctrl/Cmd + P` → 输入「每日笔记」
- ⚙️ 使用说明：仓库根目录 [[README]]

## 🧠 核心心法：双向链接
不要去维护复杂的文件夹树。写笔记时，用 `[[另一篇笔记]]` 把相关的东西连起来。
关系会自然生长，左侧的 **图谱（Graph）** 图标能帮你看见整张知识网络。

## 🗂️ 文件夹怎么用（PARA 思路）
| 文件夹 | 用途 |
| --- | --- |
| `10 Inbox` | 随手捕获，事后整理 |
| `20 项目` | 有截止日期、能完成的事 |
| `30 领域` | 长期负责的主题（如 健康、财务） |
| `40 资源` | 参考资料、素材、有趣的文章 |
| `50 归档` | 已完成 / 不再活跃的内容 |
| `60 每日笔记` | 日记与 daily log |
| `90 模板` | 笔记 / MOC / 每日笔记模板 |
| `00 索引` | MOC 内容地图（本页所在处） |

## ✅ 今天可以做的一件小事
1. 打开 `10 Inbox/欢迎.md` 看看示例笔记怎么写。
2. 按 `Ctrl/Cmd + N` 新建一条笔记，随手写点什么，再用 `[[ ]]` 连回本文。
3. 打开左侧 **图谱（Graph）** 图标，看连线出现了。

> [!tip] 小提示
> 想快速记一句话？先丢进 `10 Inbox`，有空再整理。保持「捕获」的阻力越低越好。
